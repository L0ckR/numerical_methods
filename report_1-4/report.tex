\labheading{1.1}
\task{Реализовать алгоритм $LU$-разложения с выбором главного элемента.
Решить систему линейных уравнений варианта~6, найти определитель и
обратную матрицу системы.}
\[
\begin{cases}
x_1+2x_2-x_3-7x_4=-23,\\
8x_1-9x_3-3x_4=39,\\
2x_1-3x_2+7x_3+x_4=-7,\\
x_1-5x_2-6x_3+8x_4=30.
\end{cases}
\]
\solution{}
На каждом шаге исключения выбирается максимальный по модулю элемент
текущего столбца среди оставшихся строк. Перестановки строк образуют
матрицу $P$. После исключения получается разложение $PA=LU$, где
$L$ --- нижняя треугольная матрица с единичной диагональю, а $U$ ---
верхняя треугольная матрица. Сначала прямой подстановкой решается
$Ly=Pb$, затем обратной подстановкой --- $Ux=y$. Определитель находится
как произведение диагональных элементов $U$ с учётом числа
перестановок $s$:
\[
\det A=(-1)^s\prod_{i=1}^{n}u_{ii}.
\]
Для нахождения $j$-го столбца обратной матрицы аналогично решается
система $Az_j=e_j$. Правую часть при этом также умножают на $P$.
Правильность вычислений проверяется равенствами $PA=LU$, $Ax=b$
и $AA^{-1}=I$; невязки рассчитываются до округления результата.

\labheading{1.2}
\task{Реализовать метод прогонки, задавая ненулевые элементы
трёхдиагональной матрицы и вектор правых частей. Решить систему
варианта~6.}
\[
\begin{cases}
6x_1-5x_2=-58,\\
-6x_1+16x_2+9x_3=161,\\
9x_2-17x_3-3x_4=-114,\\
8x_3+22x_4-8x_5=-90,\\
6x_4-13x_5=-55.
\end{cases}
\]
\solution{}
Для строки $a_ix_{i-1}+b_ix_i+c_ix_{i+1}=d_i$ решение представляется
в виде $x_i=p_ix_{i+1}+q_i$. Прямой ход вычисляет коэффициенты:
\[
\begin{aligned}
p_1&=-\frac{c_1}{b_1},&q_1&=\frac{d_1}{b_1},\\
p_i&=-\frac{c_i}{b_i+a_ip_{i-1}},&
q_i&=\frac{d_i-a_iq_{i-1}}{b_i+a_ip_{i-1}}.
\end{aligned}
\]
Обратный ход начинается с $x_n=q_n$, затем вычисляется
$x_i=p_ix_{i+1}+q_i$ при $i=n-1,\ldots,1$. Решение проверяется
подстановкой в исходную систему. Сложность метода --- $O(n)$.

\labheading{1.3}
\task{Реализовать методы простых итераций и Зейделя. Решить систему
варианта~6 с точностью $\varepsilon=10^{-6}$ и сравнить число итераций.}
\[
\begin{cases}
23x_1-6x_2-5x_3+9x_4=232,\\
8x_1+22x_2-2x_3+5x_4=-82,\\
7x_1-6x_2+18x_3-x_4=202,\\
3x_1+5x_2+5x_3-19x_4=-57.
\end{cases}
\]
\solution{}
Исходная система приводится к виду $x=\alpha x+\beta$:
$\alpha_{ii}=0$, $\alpha_{ij}=-a_{ij}/a_{ii}$ при $i\ne j$,
$\beta_i=b_i/a_{ii}$. Начальное приближение обоих методов равно
$x^{(0)}=\beta$. В методе простых итераций все компоненты нового
вектора вычисляются по предыдущему вектору. Метод Зейделя использует
уже обновлённые компоненты текущей итерации:
\[
\begin{aligned}
x^{(k+1)}&=\alpha x^{(k)}+\beta,\\
x_i^{(k+1)}&=\beta_i+\sum_{j<i}\alpha_{ij}x_j^{(k+1)}
+\sum_{j>i}\alpha_{ij}x_j^{(k)}.
\end{aligned}
\]
Здесь $q=\|\alpha\|_\infty=20/23<1$, что гарантирует сходимость.
Обозначив строго верхнюю часть $\alpha$ через $C$, получаем
апостериорные оценки ошибки соответственно
\[
E_{k+1}=\frac{q}{1-q}\|x^{(k+1)}-x^{(k)}\|_\infty,
\qquad
E_{k+1}=\frac{\|C\|_\infty}{1-q}\|x^{(k+1)}-x^{(k)}\|_\infty.
\]
Расчёт заканчивается при $E_{k+1}\le\varepsilon$. Дополнительно
вычисляется невязка исходной системы. Она характеризует выполнение
уравнений и может превышать заданную погрешность самого решения.
\blocktitle{Входные данные:}
\VerbatimInput{../lab1/lab1-3/input.txt}
\blocktitle{Результат работы программы:}
\VerbatimInput{../lab1/lab1-3/output.txt}
Точное решение равно $x^*=(8,-7,6,4)^T$.
Простые итерации потребовали 31 шаг, метод Зейделя --- 10 шагов.
Ошибки $\|x-x^*\|_\infty$ составили $6.24\cdot10^{-8}$
и $1.25\cdot10^{-8}$ соответственно. При одинаковом начальном
приближении метод Зейделя потребовал в $3.1$ раза меньше итераций.

\labheading{1.4}
\task{Реализовать метод вращений. Найти собственные значения и
собственные векторы симметрической матрицы варианта~6 с точностью
$\varepsilon=10^{-6}$. Проанализировать изменение погрешности
с числом итераций.}
\[
A=\begin{pmatrix}9&2&-7\\2&-4&-1\\-7&-1&1\end{pmatrix}.
\]
\solution{}
На каждой итерации выбирается максимальный по модулю
внедиагональный элемент $a_{lm}$. Для его обнуления строится
ортогональная матрица вращения $U_k$ в плоскости $(l,m)$:
\[
\varphi=\frac12\arctan\frac{2a_{lm}}{a_{ll}-a_{mm}},
\qquad \varphi=\frac\pi4\quad\text{при }a_{ll}=a_{mm}.
\]
Затем вычисляются $A_{k+1}=U_k^TA_kU_k$ и
$V_{k+1}=V_kU_k$, где $V_0=I$. Преобразование сохраняет
собственные значения исходной матрицы. Итерации продолжаются,
пока норма верхней внедиагональной части
\[
t_k=\sqrt{\sum_{i<j}(a_{ij}^{(k)})^2}
\]
превышает $\varepsilon$. Диагональные элементы итоговой матрицы
принимаются за собственные значения, а столбцы $V_k$ --- за
соответствующие собственные векторы. В выводе векторы записаны
отдельными строками. Проверяются невязки
$\|Av_i-\lambda_iv_i\|_2$ и ортогональность $V^TV=I$.
Для симметрической матрицы величина $\sqrt2\,t_k$ ограничивает
ошибку упорядоченных собственных значений.

\labheading{1.5}
\task{Реализовать $QR$-разложение и на его основе алгоритм решения
полной проблемы собственных значений. Найти собственные значения
матрицы варианта~6 с точностью $\varepsilon=10^{-6}$.}
\[
A=\begin{pmatrix}8&-1&-3\\-5&9&-8\\4&-5&7\end{pmatrix}.
\]
\solution{}
Разложение $A_k=Q_kR_k$ строится отражениями Хаусхолдера,
которые последовательно обнуляют элементы под диагональю:
\[
H=I-2\frac{vv^T}{v^Tv},\qquad
v=x+\operatorname{sign}(x_1)\|x\|_2e_1.
\]
При построении отражения принимается $\operatorname{sign}(0)=1$;
для нулевого столбца используется единичная матрица.
Следующее приближение вычисляется по формуле
\[
A_{k+1}=R_kQ_k=Q_k^TA_kQ_k,
\]
сохраняющей спектр. Итерации выполняются без сдвигов.
Изолированные блоки $1\times1$ дают собственное значение
непосредственно, для блоков $2\times2$ решается уравнение
$\lambda^2-\operatorname{tr}(B)\lambda+\det B=0$.
Блок считается изолированным, когда норма элементов под ним
не превышает $\varepsilon$; для блока второго порядка учитываются
оба столбца. Дополнительно проверяется изменение найденных корней
между соседними итерациями: оно должно быть не более $\varepsilon$.
Вычисляются невязка разложения, ортогональность $Q$ и равенство
суммы собственных значений следу исходной матрицы.
\blocktitle{Входные данные:}
\VerbatimInput{../lab1/lab1-5/input.txt}
\blocktitle{Результат работы программы:}
\VerbatimInput{../lab1/lab1-5/output.txt}
За 12 шагов найдены три действительных собственных значения.
Характеристический многочлен матрицы:
\[
\det(\lambda I-A)=\lambda^3-24\lambda^2+158\lambda-214.
\]
Первые два значения определены из блока $2\times2$, поэтому
его диагональные элементы отдельно не являются окончательными
собственными значениями. Невязка $QR$-разложения не превышает
$3.56\cdot10^{-15}$; сумма корней равна $24$ с ошибкой
$1.43\cdot10^{-14}$.

\labheading{2.1}
\task{Реализовать методы простой итерации и Ньютона. Найти
положительный корень уравнения варианта~6 с точностью
$\varepsilon=10^{-6}$. Начальное приближение определить графически,
исследовать зависимость погрешности от числа итераций.}
\[
f(x)=e^x-2x-2=0.
\]
\solution{}
Графики $y=e^x$ и $y=2x+2$ позволяют выбрать отрезок $[1;2]$.
На нём $f(1)<0$, $f(2)>0$, $f'(x)=e^x-2>0$ и
$f''(x)=e^x>0$, поэтому корень единственен. На положительной полуоси
до $\ln2$ функция убывает от $f(0)=-1$, затем возрастает,
следовательно, других положительных корней нет.
Для простой итерации принимаются
\[
\varphi(x)=\ln(2x+2),\quad x^{(k+1)}=\varphi(x^{(k)}),
\quad x^{(0)}=1.5.
\]
Выполнены $\varphi([1;2])=[\ln4;\ln6]\subset[1;2]$ и
$q=\max|\varphi'|=1/2<1$. Метод Ньютона имеет вид
\[
x^{(k+1)}=x^{(k)}-\frac{e^{x^{(k)}}-2x^{(k)}-2}{e^{x^{(k)}}-2},
\qquad x^{(0)}=2.
\]
Условие $f(2)f''(2)>0$ обеспечивает сходимость справа.
Для простой итерации и Ньютона используются оценки ошибки
\[
E_{k+1}=\frac{q}{1-q}|x^{(k+1)}-x^{(k)}|,
\qquad E_k=\frac{|f(x^{(k)})|}{e-2}.
\]
Остановка требует одновременно $E_k\le\varepsilon$ и
$|f(x^{(k)})|\le\varepsilon$. Для графика ошибки используется
контрольное значение $x^*\approx1.678346990016661$.

\labheading{2.2}
\task{Реализовать методы простой итерации и Ньютона для системы
варианта~6 при $a=3$. Найти решение с положительными координатами
с точностью $\varepsilon=10^{-6}$, графически выбрать начальное
приближение и исследовать сходимость.}
\[
\begin{cases}
x_1-\cos x_2=1,\\
x_2-\lg(x_1+1)=3.
\end{cases}
\]
\solution{}
По графикам выбирается область
$D=[0;0.05]\times[3;3.05]$ и начальное приближение
$x^{(0)}=(0.025;3.025)^T$. Здесь $\lg$ --- десятичный логарифм.
В простой итерации обе координаты обновляются одновременно:
\[
\varphi(x)=\begin{pmatrix}1+\cos x_2\\3+\lg(x_1+1)\end{pmatrix},
\qquad x^{(k+1)}=\varphi(x^{(k)}).
\]
Имеем $\varphi_1(D)=[0.00419167546;0.01000750340]$,
$\varphi_2(D)=[3;3.02118929907]$, поэтому $\varphi(D)\subset D$.
Оценка $q=\max_D\|\varphi'(x)\|_\infty=1/\ln10
\approx0.434294482<1$ гарантирует единственность решения в $D$
и сходимость. Для Ньютона обозначим $F(x)=x-\varphi(x)$:
\[
J_F(x)=\begin{pmatrix}
1&\sin x_2\\-\dfrac1{(x_1+1)\ln10}&1
\end{pmatrix},\qquad
J_F(x^{(k)})\Delta x^{(k)}=-F(x^{(k)}).
\]
Затем $x^{(k+1)}=x^{(k)}+\Delta x^{(k)}$.
На $D$ определитель якобиана больше единицы, поэтому поправка
определяется однозначно. Оценки ошибки простой итерации и Ньютона:
\[
E_{k+1}=\frac{q}{1-q}\|x^{(k+1)}-x^{(k)}\|_\infty,
\qquad E_k=\frac{\|F(x^{(k)})\|_\infty}{1-q}.
\]
Остановка требует $E_k\le\varepsilon$ и
$\|F(x^{(k)})\|_\infty\le\varepsilon$.

\labheading{3.1}
\task{По значениям функции в четырёх узлах построить
интерполяционные многочлены Лагранжа и Ньютона. Вычислить
значения многочленов и погрешность интерполяции в точке $x^*$.
Для варианта~6:}
\[
\begin{aligned}
y&=e^x,\qquad x^*=-0.5,\\
\text{а)}\quad x_i&=-2,-1,0,1,\\
\text{б)}\quad x_i&=-2,-1,0.2,1.
\end{aligned}
\]
\solution{}
Сначала вычисляются значения $y_i=e^{x_i}$ в заданных узлах.
Многочлен Лагранжа строится как сумма базисных многочленов:
\[
L_3(x)=\sum_{i=0}^{3}y_i\prod_{\substack{j=0\\j\ne i}}^{3}
\frac{x-x_j}{x_i-x_j}.
\]
Каждое слагаемое принимает значение $y_i$ в своём узле и
обращается в ноль в остальных. Для многочлена Ньютона
последовательно находятся разделённые разности:
\[
f[x_i,\ldots,x_{i+k}]=
\frac{f[x_{i+1},\ldots,x_{i+k}]-f[x_i,\ldots,x_{i+k-1}]}
{x_{i+k}-x_i},
\]
\[
P_3(x)=\sum_{k=0}^{3}f[x_0,\ldots,x_k]
\prod_{j=0}^{k-1}(x-x_j).
\]
Обе записи задают единственный многочлен степени не выше трёх,

\task{Построить кубический сплайн по табличным значениям функции,
полагая нулевую кривизну на концах: $S''(-2)=S''(2)=0$.
Для варианта~6 вычислить $S(-0.5)$.}
\[
\begin{array}{c|rrrrr}
x_i&-2&-1&0&1&2\\\hline
y_i&0.13534&0.36788&1.0&2.7183&7.3891
\end{array}
\]
\solution{}
На каждом отрезке $[x_i,x_{i+1}]$ функция представляется
кубическим многочленом
\[
S_i(x)=a_i+b_i(x-x_i)+c_i(x-x_i)^2+d_i(x-x_i)^3.
\]
Коэффициенты выбираются так, чтобы сплайн проходил через все узлы,
а его первая и вторая производные были непрерывны.
Обозначим $h_i=x_{i+1}-x_i$. Условия сопряжения приводят к
трёхдиагональной системе для $c_i$, решаемой методом прогонки:
\[
\begin{aligned}
h_{i-1}c_{i-1}+2(h_{i-1}+h_i)c_i+h_ic_{i+1}
&=3\left(\frac{y_{i+1}-y_i}{h_i}
-\frac{y_i-y_{i-1}}{h_{i-1}}\right),\\
c_0=c_4&=0,\qquad i=1,2,3.
\end{aligned}
\]
Затем вычисляются остальные коэффициенты:
\[
a_i=y_i,\quad
b_i=\frac{y_{i+1}-y_i}{h_i}-\frac{h_i}{3}(2c_i+c_{i+1}),
\quad d_i=\frac{c_{i+1}-c_i}{3h_i}.
\]
Для $x^*=-0.5$ используется многочлен на отрезке $[-1;0]$.

\labheading{3.5}
\task{Вычислить определённый интеграл варианта~6 методами
прямоугольников, трапеций и Симпсона с шагами $h_1=0.5$,
$h_2=0.25$. Оценить погрешность методом Рунге--Ромберга.}
\[
I=\int_{-1}^{1}\frac{x}{(2x+7)(3x+4)}\,dx.
\]
\solution{}
Отрезок интегрирования разбивается на $n=2/h$ равных частей,
$x_i=-1+ih$. Метод средних прямоугольников использует значение
функции в середине каждого отрезка, метод трапеций --- на его концах.
Метод Симпсона заменяет функцию параболой на каждой паре соседних
отрезков, поэтому число интервалов должно быть чётным:
\[
\begin{aligned}
I_h^{\mathrm{пр}}&=h\sum_{i=0}^{n-1}f(x_i+h/2),\\
I_h^{\mathrm{тр}}&=h\left(\frac{f(x_0)+f(x_n)}2+
\sum_{i=1}^{n-1}f(x_i)\right),\\
I_h^{\mathrm{С}}&=\frac h3\left(f(x_0)+f(x_n)
+4\sum_{\substack{i=1\\i\text{ нечётное}}}^{n-1}f(x_i)
+2\sum_{\substack{i=2\\i\text{ чётное}}}^{n-2}f(x_i)\right).
\end{aligned}
\]
Расчёты выполняются с обоими шагами. При $k=h_1/h_2=2$
поправка Рунге--Ромберга, оценка ошибки на мелкой сетке и
уточнённый интеграл равны
\[
\delta=\frac{I_{h_2}-I_{h_1}}{2^p-1},\qquad
R_{h_2}=|\delta|,\qquad I_{\mathrm{RR}}=I_{h_2}+\delta.
\]
Используются $p=2$ для прямоугольников и трапеций, $p=4$ для
Симпсона. Оценка относится к шагу $0.25$ и является
асимптотической, а не строгой верхней границей ошибки.

\labheading{4.1}
\task{Реализовать методы Эйлера, Рунге--Кутты и Адамса четвёртого
порядка для решения задачи Коши. Решить задачу варианта~6 с шагом
$h=0.1$, построить графики и оценить погрешность по точному решению
и методом Рунге--Ромберга.}
\[
\begin{gathered}
y''+4xy'+(4x^2+2)y=0,\qquad x\in[0;1],\\
y(0)=1,\qquad y'(0)=1,\qquad y(x)=(1+x)e^{-x^2}.
\end{gathered}
\]
\solution{}
Вводится переменная $z=y'$, после чего уравнение преобразуется
в систему $y'=z$, $z'=-4xz-(4x^2+2)y$. Для вектора
$u=(y,z)^T$ обозначим правую часть через $F(x,u)$.
В явном методе Эйлера обе компоненты вычисляются по состоянию
на предыдущем шаге: $u_{i+1}=u_i+hF(x_i,u_i)$.
Метод Рунге--Кутты использует четыре оценки правой части:
\[
\begin{aligned}
k_1&=hF(x_i,u_i),&k_2&=hF(x_i+h/2,u_i+k_1/2),\\
k_3&=hF(x_i+h/2,u_i+k_2/2),&k_4&=hF(x_i+h,u_i+k_3),\\
u_{i+1}&=u_i+(k_1+2k_2+2k_3+k_4)/6.
\end{aligned}
\]
Первые четыре узла для Адамса получаются методом Рунге--Кутты,
после чего применяется формула
\[
u_{i+1}=u_i+\frac h{24}
(55F_i-59F_{i-1}+37F_{i-2}-9F_{i-3}).
\]
Расчёты повторяются с шагом $h/2$. Оценка ошибки мелкой сетки
в общих узлах равна
\[
R_{h/2}=\max_i\frac{|y_{h/2}(x_i)-y_h(x_i)|}{2^p-1},
\]
где $p=1$ для Эйлера, $p=4$ для Рунге--Кутты и Адамса.
Также вычисляется максимальное отклонение от точного решения
на каждой полной сетке.

\VerbatimInput{../lab4/lab4-1/input.txt}
\blocktitle{Результат работы программы:}
\VerbatimInput{../lab4/lab4-1/output.txt}
Точное решение удовлетворяет начальным условиям; его производные
\[

\labheading{4.2}
\task{Реализовать метод стрельбы и конечно-разностный метод для
краевой задачи варианта~6. Построить графики решений, оценить

\[
\begin{gathered}
y''-2(1+\tan^2x)y=0,\qquad x\in[0;\pi/6],\\
y(0)=0,\qquad y(\pi/6)=-\frac{\sqrt3}{3},\qquad
y(x)=-\tan x.
\end{gathered}
\]
\solution{}
Выбираются десять равных отрезков с шагом $h=\pi/60$.
В методе стрельбы задаётся параметр $\eta=y'(0)$ и решается
задача Коши для системы $y'=z$, $z'=2(1+\tan^2x)y$
методом Рунге--Кутты четвёртого порядка. Остаток правого
граничного условия $\Phi(\eta)=y(\pi/6;\eta)+\sqrt3/3$
обнуляется методом секущих:
\[
\eta_{k+1}=\eta_k-
\Phi(\eta_k)\frac{\eta_k-\eta_{k-1}}
{\Phi(\eta_k)-\Phi(\eta_{k-1})}.
\]
Начальные значения равны $\eta_0=0$, $\eta_1=-2$;
остановка происходит при $|\Phi|\le10^{-12}$.
Конечно-разностный метод заменяет вторую производную
центральной разностью:
\[
\frac{y_{i-1}-2y_i+y_{i+1}}{h^2}-2\sec^2x_i\,y_i=0.
\]
Граничные значения задаются точно, трёхдиагональная система
решается прогонкой. Для оценки ошибки расчёт повторяется
с шагом $h/2=\pi/120$:
\[
R_{h/2}=\max_i\frac{|y_{h/2}(x_i)-y_h(x_i)|}{2^p-1},
\]
где $p=4$ для стрельбы и $p=2$ для конечных разностей.
Погрешности дополнительно определяются сравнением с $-\tan x$.
